# K3 · 真机验收矩阵

> 归属：K2 · 依据：`docs/wechat-build.md` §5、当前双端功能集（角色/弯道/道具/主题/音效/存档/遥测）
> 消费方：step-5 出包后逐项自测，结果回填本文件

## 1. 机型矩阵

| 档 | 代表机型 | 关注点 | 通过阈值 |
|---|---|---|---|
| 高端 | iPhone 14+/骁龙 8 系 | 帧率上限、发热 | 帧率稳定 60，10 分钟不降频 |
| **中端（基准）** | 骁龙 7 系/天玑 8000 系 | **主要验收机** | 帧率 **≥55**，无卡顿 |
| 低端 | 骁龙 6 系/4GB 内存 | 内存峰值、加载 | 帧率 ≥30，不闪退 |
| 老旧 iOS | iPhone X/SE2 | WebGL 兼容 | 可玩，无渲染异常 |

## 2. 功能验收项（逐项勾选）

### 核心玩法
- [ ] 扫码进入，开始界面完整（标题/最高进度/操作说明/本关目标）
- [ ] 拖动转向跟手（无延迟感、无反向）
- [ ] A/D 键（模拟器）转向正常
- [ ] 吃砖拾取正常，+N 飘字出现
- [ ] 断崖处砖够自动铺桥，铺桥有震屏+减速反馈
- [ ] 砖不够掉落，掉落有慢动作
- [ ] 终点门验砖，胜利结算面板弹出
- [ ] 胜利：星级动画/用时/余砖/最佳成绩显示正确
- [ ] 失败：同关换图重试（图变了，关卡号不变）

### 道具
- [ ] L3 起出现 +N 门（蓝底白字）
- [ ] L4 起出现 ×2 门（红底白字）
- [ ] L6 起出现加速鞋，吃鞋有提速反馈
- [ ] 过门砖数变化与门面数字一致

### 表现层
- [ ] 角色关节动画正常（跑步步态/胜利举手/落水旋转）
- [ ] 砖垛在怀里可见（追尾相机下不被遮挡）
- [ ] 弯道 L4+ 生效，道路/物体随弯
- [ ] 相机贴路径后方，过弯不穿模
- [ ] 主题换肤（T 键）三盘切换正常
- [ ] 音效：吃砖/铺桥/胜利/失败四音齐全，M 静音有效

### 系统
- [ ] 进度存档：关掉小程序重开，关卡号保留
- [ ] 星级/最佳成绩持久化正确
- [ ] 遥测落盘（`sr_telemetry_v1`），`dumpTelemetry()` 可导出

## 3. 中断与边界场景（易漏，必测）

| 场景 | 期望 |
|---|---|
| 游戏中断网 | 不崩溃，单机玩法不受影响 |
| 切后台再回前台 | 状态恢复，不重开当前关 |
| 广告播放中切后台 | 回来后广告正确结束/复原，游戏可继续 |
| 连续快速点击开始按钮 | 不重复创建场景 |
| 长时间挂机（5 分钟） | 无内存泄漏增长、帧率不衰减 |
| 弱网下加载 | 有加载提示，不白屏 |

## 4. 性能指标

| 指标 | 阈值 | 测量方式 |
|---|---|---|
| 帧率（中端机） | ≥55 | 微信开发者工具性能面板 |
| 内存峰值 | ≤300 MB | 同上 |
| 首屏加载 | ≤5 s（4G） | 真机计时 |
| 包体 | ≤4 MB | `check-bundle.mjs` |
| 单局时长 | L1≈16s → L10≈22s | 与设计一致（PROGRESS.md） |
