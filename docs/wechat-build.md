# 微信小游戏构建预演（V5）

> 目标：Cocos 工程 → 微信小游戏包 → 真机预览。本文件是执行清单，构建时逐步核对。

## 1. 构建前检查（Cocos 编辑器内）

| 项 | 位置 | 目标值 |
|---|---|---|
| 屏幕方向 | 项目设置 → 项目数据 → 屏幕 | **竖屏**（Portrait） |
| 设计分辨率 | 同上 | 720 × 1280（适配主流竖屏） |
| 引擎版本 | 主页 Dashboard | 3.8.x LTS |
| 包体预算 | 见下表 | 主包 ≤ 4MB |

## 2. 构建步骤

1. Cocos 菜单 **项目 → 构建发布**，平台选 **微信小游戏**
2. 发布路径填 `build/wechatgame`（已进 .gitignore）
3. 点 **构建**，等编译完成（首次 3-5 分钟）
4. 打开 **微信开发者工具** → 导入 → 选择 `build/wechatgame` 目录 → 项目类型选**小游戏**，AppID 选“测试号”或你自己的
5. 工具里点**预览**生成二维码，手机扫码真机试玩；点**真机调试**可看日志

## 3. 包体预算（我们当前状态）

| 内容 | 预估 | 说明 |
|---|---|---|
| 引擎 + 代码（主包必需） | ~2.5-3.5MB | Cocos 3D 小游戏压缩后基线 |
| 我们的代码/场景 | <50KB | 纯代码无资源 |
| 音效（4 个 mp3） | <300KB | 按 docs/audio-assets.md 清单 |
| **合计** | **≈3-3.8MB** | 贴 4MB 上限，**富余量小** |
| 主题/皮肤/多余关卡 | 走 CDN | 资源放远程服务器，`bundle` 配置远程加载 |

> 超过 4MB 的方案：① 音效全部改 WebAudio 合成（浏览器版已验证的路线，0 体积）② 开分包 ③ 资源上 CDN。

## 4. 已知坑（提前记）

- **触摸**：我们只绑 `Input.EventType.TOUCH_*`，真机直接用；PC 预览鼠标会被 Cocos 映射成触摸（已验证）
- **音频**：微信小游戏音频必须走 `wx.createInnerAudioContext` 或 Cocos 的适配层——`AudioMgr.ts` 用 Cocos 标准 API，发布到微信时引擎会自动适配；真机无声先查这里
- **localStorage**：progression 用 `sys.localStorage`，微信端自动映射到 `wx.getStorageSync`（Cocos 适配），无需改代码
- **性能**：真机看帧率（微信开发者工具可杜邦）；盒子数量 ~200 个共享网格，低端机应无压力
- **版号**：体验版/开发版不需要版号；正式上架卖广告前必须版号（见 docs/compliance.md）
