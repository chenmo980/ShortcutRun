# 微信小游戏上架合规清单

> 原则：资质周期长（软著 1-2 月、版号 3-6 月），**与开发并行启动**，不要等游戏做完才办。

## 一、正式上架需要的资质

| 资质 | 周期 | 说明 |
|---|---|---|
| **企业营业执照** | 1-2 周 | 游戏类目个人主体走不通；虚拟支付/内购必须企业主体 |
| **软著**（计算机软件著作权登记证书） | 30-60 个工作日 | 中国版权保护中心申请，可加急 |
| **版号**（游戏出版备案 / ISBN） | 3-6 个月 | 最大的一道坎。需企业主体 + 出版单位通道；2024 年起微信小游戏上架（含纯 IAA）也要求版号 |
| **ICP 备案** | 与小程序注册同步 | 微信小程序基础要求 |
| **小程序认证** | 当天 | 企业主体 300 元/年 |

## 二、软著材料清单（现在就能递）

1. 申请表（在线填报：软件全称、版本号 V1.0、开发完成日期）
2. **源代码**：前后各 30 页（共 60 页），每页 50 行，去除空行——我们目前约 1000 行，够
3. 说明书/用户手册：游戏截图 + 玩法说明（灰模截图即可，后期可补但不影响拿证）
4. 身份材料：企业执照或身份证
5. 注意：软件名称不能与已登记的重名；版本号从 V1.0 起

## 三、版号注意事项（提前避坑）

- **名称预审**：游戏名不能与已上架游戏重名，"Shortcut Run" 是 VOODOO 的商标，**必须改名**（复刻项目的既定决策）
- 题材不能踩红线（我们这种休闲跑酷无碍）
- 需要出版社/出版单位做前置审批，通常找代理

## 四、微信侧流程顺序

```
注册小程序（企业）→ 认证 → 选"游戏"类目
  → 开发版/体验版自测（不需要版号，体验成员制）
  → 留存数据验证（G1 之后的真机数据）
  → 流量主开通（累计 UV ≥ 1000 才能开广告）
  → 提审（需版号）→ 发布
```

## 五、风险备忘

- **换皮风险**：玩法不受版权保护，但美术资产/名字/UI 抄袭会被投诉下架——我们的对策就是自有美术 + 改名，已在执行
- **版号期间**：先以体验版收集数据、调产品，版号下来再上架接广告，节奏不冲突

## 六、建议启动时间

| 事项 | 启动时机 |
|---|---|
| 企业主体注册 | 现在（越早越好，其他都依赖它） |
| 软著递件 | 现在（材料就是现有代码 + 一份说明） |
| 版号启动 | G1 手感过后（避免给一个会被砍的产品浪费版号钱） |
| 流量主 | 体验版有真实用户后 |
