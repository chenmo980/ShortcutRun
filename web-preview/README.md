# 浏览器试玩版（灰模）

给手感验证（G1）用的零安装版本：**双击 `index.html` 就能玩**，不需要 Cocos、不需要任何环境。

- 逻辑与 Cocos 版完全一致（同一份关卡生成、同一套参数、含扫掠检测修复）
- 操作：点击开始，鼠标拖动 / `A` `D` 转向
- 自动重开：胜利/失败 1.6 秒后换新关卡

## 自动化验证

```bash
node tools/verify-web.mjs
```

无头 Chromium 实跑，10 项断言全过：开始/吃砖/转向/铺桥/掉落/胜利/无页面错误/画面渲染/玩家可见。

> 说明：`three.min.js` 是本地依赖（three r149 UMD 构建），离线可用，勿删。
